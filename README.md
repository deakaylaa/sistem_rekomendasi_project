# East Java Educational Needs Recommendation System

This is a Data Science project developed for the 2025 Recommendation Systems course. It aims to analyze and visualize educational needs in East Java, Indonesia. The application is built using **Streamlit** and **Python**.

---

## Project Overview
This system provides a quick overview of educational conditions for every City/Regency in East Java based on 2022 data. It helps to identify gaps in school facilities and teacher availability.

## Research Goals
* To calculate student-to-teacher and student-to-school ratios.
* To compare regional data with the provincial average.

## File Structure
* `app.py`: Main Streamlit application and UI.
* `data_processing.py`: Data loading, cleaning, and feature engineering.
* `data jatim 2022 pendidikan.xlsx`: Dataset from BPS East Java 2022.
* `requirements.txt`: Required Python libraries.
* `.gitignore`: Files and folders excluded from version control.

## Key Features
* **Interactive Dashboard**: Select any city in East Java to see its profile.
* **Smart Analysis**: Automatic insights for Elementary and Junior High levels.
* **Comparative Visuals**: Side-by-side bar charts comparing local vs. provincial data.
* **Demographic Insights**: Analysis of population density impact on education.

## Tech Stack
* **Python**: Core programming language.
* **Pandas & NumPy**: For data manipulation and calculations.
* **Matplotlib & Seaborn**: For creating charts.
* **Streamlit**: For the web application interface.
